# AI Agent Playbook

AI Agent Playbook 是一份面向产业实践的系统化手册，围绕 Agent 如何理解任务、规划与执行、调用工具、管理状态、验证结果以及持续学习展开。

内容覆盖框架与模型选型、上下文工程、记忆系统、微调与强化学习、多 Agent 协作、评测与可观测性、生产可靠性、安全治理、持续进化机制和产业案例，重点讲清楚从原理判断到工程落地的完整路径。
